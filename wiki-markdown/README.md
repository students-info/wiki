# Студентс Инфо

Статический Markdown-вики-сайт на HTML, CSS и JavaScript с интерфейсом, стилизованным под современный Wikipedia Vector 2022.

## Запуск

```bash
python -m http.server 8000
```

Откройте `http://localhost:8000/`.

## Добавление статьи

1. Создайте Markdown-файл, например `articles/example.md`.
2. Добавьте его в `content-index.json`:

```json
[
  {
    "title": "Название статьи",
    "path": "articles/example.md"
  }
]
```

Статья будет доступна по адресу `?article=articles/example.md`.

## Интерфейс

- верхняя панель и поиск в стиле Wikipedia Vector 2022;
- автоматическое боковое оглавление из `##`–`######`;
- адаптивная левая навигация;
- настройки размера текста, ширины страницы и темы;
- поисковые подсказки по `content-index.json`;
- мобильная версия;
- Markdown/Obsidian-ссылки, таблицы, callout-блоки, task-list, код и изображения.

Если в старой статье есть вручную созданный раздел `## Содержание`, он скрывается при рендеринге, поскольку оглавление строится автоматически слева.
